### Acceptance Record

To accept this Agreement, run the following command from the root of the Project repository, with the GitHub CLI authenticated as the account you will use to open your pull request:

```bash
python3 scripts/accept-cla.py
```

The script creates an acceptance record at `cla/accepted/<github-user-id>.md`. The record identifies your GitHub account by its numeric user ID and username, records the version and SHA-256 digest of this Agreement, and includes an explicit acceptance statement.

You must include this record in the pull request that contains your Contribution. The Project's automated checks verify that the record is valid for the current version of this Agreement before the pull request can be accepted.

You only have to do this once for each version of this Agreement. When the Maintainer publishes a new version, you will be asked to accept it before your next Contribution.
